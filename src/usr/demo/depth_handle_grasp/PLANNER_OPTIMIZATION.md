# RobotSession 规划优化实测（2026-10-27）

本次保留现有 RobotSession、标定与视觉算法，未迁移 MTC，未发送机械臂或夹爪执行命令。基线在修改前保存于 [baseline](reports/planner_optimization_20261027_165937/baseline)，包含 SHA256 清单。

## 结果与根因

原搜索找到完整解后仍继续比较候选，导致第一次约 11.88 秒成功，约 20.31 秒才返回。已默认改为 `planning_mode: first_feasible`，完整六阶段全部通过后立即返回。`best_within_budget` 保存最佳完整解；后续候选失败或超时不会覆盖已有解。完成解检查点、最终轨迹和成功状态分别保存，规划成功与执行成功分开记录。

原实现已经使用上一有效关节解作为连续 IK 初值。实测主要瓶颈是重复 CAD 变换和密集点云距离查询，并非数值 IK 本身，因此保留求解器和控制器关节语义。

同一历史场景 `20261027_163257`、起始关节、候选与放置目标的结果：

| 指标 | 原始实现 | 仅修复立即返回 | 最终实现 |
|---|---:|---:|---:|
| 首次完整解 / 搜索返回（秒） | 11.88 / 20.31 | 11.87 / 11.87 | 3.82 / 3.82 |
| IK 调用 | 163 | 95 | 95 |
| 关节状态检查 | 361 | 218 | 218 |
| MoveIt 碰撞服务调用 | 722 | 436 | 436 |

最终完整规划计时为 **6.11 秒**，包含候选评分、场景构建与搜索，排除视觉和 ROS 初始化；整次回放含初始化为 7.35 秒。搜索的 3.82 秒不能当成整个感知抓取任务耗时。

带统计、尚未优化几何查询的版本，218 次状态检查累计 8.58 秒，数值 IK 95 次累计 0.584 秒。优化后相同检查数累计 0.498 秒，数值 IK 仍约 0.584 秒。候选评分由 3.77 秒降至 0.785 秒。相同已选轨迹的必要状态检查没有省略。

## 实现与约束

- CAD 几何按精确夹爪宽度及安装变换缓存，只缓存不可变几何，不缓存可变场景下的碰撞结论。返回数组独立复制。
- 每组原始 CAD 样本的包围球覆盖全部样本。只有 `最近障碍点到球心的距离 - 半径 >= 原安全距离` 时才证明整组安全；无法证明时执行原密集查询。名义与标定偏置状态的 MoveIt 检查均保留。
- 连续 IK 保留原关节限位、FK 误差阈值、分支跳变检查和偏置只应用一次的语义。局部失败最多细分两层（配置硬上限三层）；碰撞和超时不通过重试绕过。
- 可选 `coarse_check` 默认 9 mm，仅作预检查，不产生执行轨迹。通过后仍必须执行不大于 3 mm 的精细检查。实测可行场景开启粗筛为 4.60 秒、127 次 IK，反而增加开销，故 `coarse_check_enabled: false` 为默认值。
- 保留两种 flip 的实际端点可达性与运动量筛选，不固定优先某一种朝向。已有解立即返回后无需再为其他候选做重复完整验证。
- `planning_performance.json` 使用单调时钟、内存缓冲，记录评分、场景、端点、逐段路径、数值 IK 与碰撞次数及平均/P95、每段点数和 IK 失败数、首次解及最终返回时间。嵌套计时会重叠，不能直接相加。失败与预算耗尽也输出统计。
- `planning_search.json` 区分首次解返回、预算耗尽且已有解、预算耗尽且无解、搜索范围耗尽；“无可行解”指本次候选搜索集合，不是数学上的全局无解证明。
- 预算为协作式检查，正在进行的 ROS 调用和清理可能造成少量超出，不保证硬实时截止。

## 仍存在的失败与边界

历史约 163–165° 的超限主要来自第六关节的另一 IK 分支；仍按原运动量约束拒绝，未放宽限制。link2 碰撞仍真实存在于相应模型与目标中，失败报告保存接触对、检查关节状态、名义/偏置基准及控制器关节状态，未删除必要障碍模型。

现有观测障碍包含非目标点云（可能包括线缆），不是经过语义确认的篮体分割。本次没有擅自过滤。现有系统还没有经过验证的刚性随动篮体附着模型与完整篮体竖直姿态约束，因此不能把这些项目标记为已验证；3/3 是历史场景规划成功率，不是实机抓取成功率。
